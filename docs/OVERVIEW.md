# Overview

Zyvor Stays is self-hosted travel booking software with an Apple-inspired guest and host experience.

## What you see on the demo

- Discover stays inspired by places across **India**, **neighbouring countries**, and **Europe**
- Browse a **fictional data only** collection with destination photography
- Save favourites, trip boards and arrival plans after sign-in
- Host console for inventory, rates and Gap Radar
- Guests **pay at property** — reservations confirm without online payment

## What this site is not

- Not application source (that lives in a private repository)
- Not a Booking.com API integration
- Not a certified tax, payment or travel-agency system
